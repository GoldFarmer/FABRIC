# Nexus Mods listing

## Name

FABRIC - Outfit Indicators

## Description

Displays indicators on clothing when they are associated with outfits, listing how many and which outfits they are used by.

**Character count:** 122 / 350

## Listing

[size=4][b]Description[/b][/size]
FABRIC shows which saved outfits use each clothing item. It adds a configurable marker to associated item cards and shows the number and names of related outfits in the normal item tooltip.

[size=4][b]Installation instructions[/b][/size]
[list=1]
[*]Install the required dependencies listed below.
[*]Extract the FABRIC release ZIP into the Cyberpunk 2077 game directory, preserving its folder structure.
[*]Start the game. FABRIC builds its outfit-association cache after the player loads.
[/list]

Do not copy a [b]Logs.reds[/b] file from another mod into the FABRIC folder. The shared logging declarations are installed once at [b]r6\scripts\Logs.reds[/b].

[size=4][b]Main features[/b][/size]
[list]
[*]Shows a configurable marker on clothing associated with one or more saved outfits.
[*]Shows the number of associated outfits directly on the marker.
[*]Adds an [b]Outfits:[/b] section with the associated outfit names to the normal item tooltip.
[*]Supports Equipment-EX Wardrobe, player Backpack and stash, and Virtual Atelier catalog cards.
[*]Preserves exact owned-item associations in Wardrobe and inventory views while recognizing matching clothing records in Virtual Atelier.
[*]Lets Mod Settings users choose the marker icon, color, and card corner.
[/list]
